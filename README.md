# cl-nica-odonto-02

Clínica Odontológica - Sistema Fluxo de Caixa Médio Porte
Desenvolvido por Gomes Do Carmo - feito no celular, pronto para GitHub.

Como instalar (PC ou hospedagem)
Crie o banco e importe install.sql
Edite conexao.php com host/user/pass
Acesse index.php
Funcionalidades
Faturamento Mês / Despesas / Lucro / A Receber
Cadastro de Pacientes, Dentistas, Categorias
Lançamento com parcelas (ex: Ortodontia 10x) -> gera parcelas automaticamente
Comissão automática por dentista
Últimos lançamentos com filtro
Mobile Version
Para testar no celular sem MySQL, use a versão single-file clinica_v2.php (localStorage)
